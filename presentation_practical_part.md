## `01_detection.ipynb` — Детекция транспортных средств и номерных знаков

### Цель
Построить двухуровневый детектор: сначала найти автомобиль на изображении, затем локализовать его номерной знак и распознать текст.

### Инструменты и библиотеки
- **Ultralytics YOLOv8n** — архитектура детектора (3.2M параметров)
- **EasyOCR** (CRAFT + CRNN) — распознавание текста номера
- **OpenCV, PIL, matplotlib** — обработка и визуализация
- **Kaggle API** — автоматическая загрузка датасета

### Данные

| Датасет | Назначение | Размер | Формат |
|---|---|---|---|
| COCO 2017 (предобученные веса) | Детекция ТС | 118k изображений | YOLO pretrained |
| andrewmvd/car-plate-detection (Kaggle) | Fine-tuning детектора номеров | 433 пары img+XML | Pascal VOC |

Датасет номерных знаков содержит оба формата (`.jpg` и `.png`). Разбивка: **347 train / 86 val** (80/20, seed=42).

### Методология

**Детекция ТС:** YOLOv8n, предобученный на COCO, используется без дообучения. Целевые классы COCO: `car (2), motorcycle (3), bus (5), truck (7)`.

**Fine-tuning детектора номеров:**
- Базовая модель: `yolov8n.pt` → 1 класс `license_plate`
- Оптимизатор: SGD, lr=0.01, cosine annealing
- Параметры: 50 эпох, batch=16, imgsz=640, patience=15, weight_decay=5×10⁻⁴
- Устройство: Tesla T4 (CUDA)

**OCR:** EasyOCR с языками `['ru', 'en']`. Пост-обработка: перевод латинских букв в кириллические эквиваленты (A→А, B→В и т.д.), фильтрация по regex `[АВЕКМНОРСТУХ]\d{3}[АВЕКМНОРСТУХ]{2}\d{2,3}`.

### Анализ кривых обучения

Обучение YOLOv8n сопровождается тремя компонентами функции потерь.

**Train Box Loss (CIoU)** — штрафует за неточность координат bbox: учитывает перекрытие, расстояние между центрами и несовпадение пропорций. Снижается плавно (1.50 → 0.95) с осцилляциями: точная локализация номерного знака — геометрически сложная задача, которая требует больше итераций, чем классификация.

**Train Cls Loss (BCE)** — бинарная кросс-энтропия для 1 класса (`license_plate` vs фон). Падает резко в первые 5 эпох (3.0 → 1.0), затем медленно снижается до 0.5. Быстрый старт объясняется простотой задачи: с единственным классом модель быстро выучивает «есть номер / нет номера», не путая классы между собой.

**Train DFL Loss** — Distribution Focal Loss; вместо скалярного предсказания координат модель учит дискретное распределение по бинам. На эпохах 3–7 наблюдается небольшой рост (1.19 → 1.27) перед снижением до 1.02. Это нормально: пока backbone не даёт стабильных признаков, модель «расшатывает» распределение в разные стороны, прежде чем зафиксироваться на правильных бинах.

**Test mAP@0.5** — характерная «ямка» на эпохах 2–3 (0.45 → 0.20): в начале обучения модель агрессивно предсказывает боксы (высокий Recall, низкий Precision), что даёт иллюзию работы на эпохе 1; затем порог уверенности эффективно поднимается, число ложных срабатываний падает — вместе с ним временно падает и mAP. С эпохи 5 начинается устойчивый рост до 0.91.

**Test Box Loss** — аномальный рост с 1.35 до 1.75 на эпохах 5–10, после чего снижение до 1.42. Это типичный эффект для детекторов: пока Task-Aligned Assigner настраивает назначение якорей под тренировочную выборку, на тестовой выборке боксы временно ухудшаются. После стабилизации назначений box loss начинает падать вместе с тренировочным.

1. **До/После fine-tuning** — один кадр test-выборки с COCO pretrained vs дообученным детектором
2. **Grid порогов уверенности** — один кадр при conf = 0.2 / 0.4 / 0.6 / 0.8
3. **Примеры False Negative** — кадры, где детектор пропустил номер (IoU < 0.5, GT зелёным, pred синим)
4. **IoU-анализ** — гистограмма распределения IoU + CDF по всей test-выборке

## `02_color_classifier.ipynb` — Классификация цвета автомобиля

### Цель
Определить цвет автомобиля по его кропу (вырезанному bbox из детектора). 9 классов: black, white, silver, red, blue, yellow, green, brown, orange.

### Инструменты и библиотеки
- **ResNet18** (torchvision, ImageNet pretrained) — backbone классификатора
- **PyTorch** — обучение, аугментации, DataLoader
- **scikit-learn** — метрики (confusion matrix, classification report, top-k accuracy)
- **seaborn / matplotlib** — визуализация

### Данные

| Датасет | Источник | Размер | Классов |
|---|---|---|---|
| VCoR (Vehicle Color Recognition) | Kaggle (`landrykezebou/vcor-vehicle-color`) | ~15k | 9 |

После фильтрации до 9 нужных классов: **Train 4 789 / Val 1 022**.

### Методология

**Двухфазное обучение ResNet18:**
- **Фаза 1 (эпохи 1–4):** backbone заморожен, обучается только `fc`-слой. Оптимизатор: Adam, lr=1×10⁻³
- **Фаза 2 (эпохи 5–20):** backbone размораживается полностью, lr снижается до 1×10⁻⁴

Последний слой: `Dropout(p=0.4) → Linear(512, 9)`  
Loss: `CrossEntropyLoss(label_smoothing=0.1)`  
Аугментации: RandomResizedCrop(224), RandomHorizontalFlip, ColorJitter, RandomGrayscale, RandomErasing

### Динамика обучения

|---|---|---|
| 1 | Старт (только fc) | 0.681 |
| 4 | Конец фазы 1 | 0.781 |
| **5** | **Разморозка backbone** | **0.889 (+10.8% за 1 эпоху)** |
| 6 | — | 0.923 |
| 18 | Best | **0.935** |
| 20 | Конец | 0.934 |

Время обучения: ~17 мин на Tesla T4.

| white | 0.976 | 0.953 | **0.965** | 86 |
| blue | 0.968 | 0.962 | **0.965** | 159 |

- **PyTorch** — обучение, two-phase fine-tuning
- **scikit-learn** — top-k accuracy, confusion matrix, classification report
- **seaborn / matplotlib** — визуализация

### Данные

## `04_pipeline_final.ipynb` — Финальный сквозной пайплайн

### Цель
Объединить все обученные модели (детектор ТС, детектор номеров, классификатор цвета, классификатор кузова, OCR) в единый пайплайн и запустить его на реальном видеофайле.

### Инструменты и библиотеки
- **YOLOv8n** (COCO pretrained) — детекция ТС
- **YOLOv8n fine-tuned** (`yolov8n_plates.pt`) — детекция номеров внутри кропа ТС
- **ResNet18** (`color_resnet18.pth`, `body_resnet18.pth`) — цвет и тип кузова
- **EasyOCR** — распознавание текста номерного знака
- **OpenCV** — чтение/запись видео, аннотирование кадров
- **TensorBoard** — логирование детекций по кадрам

### Загружаемые веса

| Модель | Файл | Источник |
|---|---|---|
| YOLOv8n (ТС) | `yolov8n.pt` | Ultralytics (автозагрузка) |
| YOLOv8n (номера) | `yolov8n_plates.pt` | Обучен в ноутбуке 01 |
| ResNet18 (цвет) | `color_resnet18.pth` | Обучен в ноутбуке 02 |
| ResNet18 (кузов) | `body_resnet18.pth` | Обучен в ноутбуке 03 |

### Архитектура пайплайна

Для каждого кадра видео выполняется следующая цепочка:

```
Кадр
  └→ YOLOv8n (ТС) → bbox каждого ТС
        └→ кроп ТС → ResNet18 (цвет)   → label + уверенность
        └→ кроп ТС → ResNet18 (кузов)  → label + уверенность
        └→ кроп ТС → YOLOv8n (номер) → кроп номера → EasyOCR → текст
        └→ аннотированный кадр (bbox + метки)
  └→ запись кадра в output_video.mp4
```

**Функции пайплайна:**
- `classify(model, labels, img_crop_bgr)` — классификация кропа через ResNet18 (Softmax → argmax)
- `detect_plate(vehicle_crop, plate_model)` — поиск номера внутри bbox ТС (conf=0.3)
- `read_plate_ocr(plate_crop, reader)` — EasyOCR + нормализация кириллицы + regex
